The connection between longest common subsequence and diff algorithms
=====================================================================

If you read `the diff program's Wikipedia page <wiki_>`_, you might be intrigued by the following sentence:

   The operation of diff is based on solving the longest common subsequence problem.

.. _wiki: https://en.wikipedia.org/wiki/Diff

I'm writing a `Software-Foundations <SF_>`_-style series to explicitate that idea.
I made up a name for it: *Difftopia*.

Having worked through volume 1 of Software Foundations is a prerequisite. There are no HTML rendering, only the Rocq files.

You can find the first part :download:`here </rocq/difftopia1.v>`.

.. _SF: https://softwarefoundations.cis.upenn.edu/
